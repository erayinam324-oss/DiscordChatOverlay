GitHub repo adını buraya yazarsan uygulama her açıldığında yeni sürümü otomatik indirip kendini günceller (ayarların silinmez).

Hızlı Kurulum
  1. Discord masaüstü uygulaması açıkken yukarıdaki ↗ StreamKit butonuna tıkla.
  2. Install for OBS → Authorize yaptıktan sonra Chat Widget linkini kopyalayıp Sohbet sekmesine yapıştır.
  3. İstersen Status Widget linkini de Durum Banner sekmesine ekle.

İpucu: Katmanı taşımak için üst kenardaki ince tutamacı sürükle, sağ tıkla hızlı menüyü aç.
